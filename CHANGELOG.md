# Changelog

## [0.2.0] - 2026-09-13

### Added
- Knip configuration for unused code detection
- Complete UI component library:
  - Button (5 variants: primary, secondary, outline, ghost, danger)
  - Input (with validation, password toggle, icons)
  - Card (default, flat, interactive, selected variants)
  - Modal (5 sizes: sm, md, lg, xl, full)
  - Toast notifications (success, error, warning, info)
  - Loading/Spinner (sm, md, lg sizes)
  - Timer component (for cooking)
  - Badge (6 color variants)
  - Avatar (with initials and status indicator)
  - Tag/Chip (removable)
  - Dropdown menu
  - Tooltip
  - Progress bar
  - Rating (star system)

- Main Layout with:
  - Mobile header with hamburger menu
  - Desktop sidebar navigation
  - Mobile bottom navigation bar
  - Responsive design

- Auth Layout with gradient background

- Authentication pages:
  - Login page
  - Register page (with cooking level selection)
  - Forgot password page

- Dashboard page with:
  - Welcome greeting
  - Quick stats cards
  - Quick actions (AI generate, Pantry, Calendar)
  - Today's meals list
  - Suggested recipes
  - Weekly progress

- Feature placeholders:
  - Pantry
  - Recipes
  - Calendar
  - Household
  - AI Config
  - Settings

### Changed
- Updated app routes to use layouts
- Enhanced progress tracking
